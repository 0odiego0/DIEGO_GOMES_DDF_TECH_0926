# Data App

Explora a amostra `data/refined/features_amostra.csv`: filtro por categoria e faixa de preço, e cinco produtos parecidos pelo texto do título e da descrição.

Na raiz do repositório:

```bash
pip install -r app/requirements.txt
streamlit run app/streamlit_app.py
```
